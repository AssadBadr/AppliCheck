## 🎯 The 60-Second Pitch

**Problem:**  
Grant applicants get vague "incomplete" emails → don't know what to fix → think their idea got rejected → weeks of confusion

**Solution:**  
Dashboard shows caseworkers EXACTLY what documents are missing/mismatched → generates precise email feedback → applicant knows what to fix

**Demo:**  
Click APP-002 → see 3 specific issues → generate email → simulate fix → ✅ review ready

**Impact:**  
40% fewer emails, 60% faster resolution, no more ambiguity

## 🆘 If Something Breaks

```bash

```

### Port already in use
```bash

npx kill-port 5173
npm run dev
```

### Demo freezes
- Refresh browser
- Click "Reset Demo" button
- Or open `initial.json` and walk through data manually
